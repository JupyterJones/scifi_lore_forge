# StellarForge • Sci-Fi Lore & Concept Art Studio 🚀🪐

An AI-powered creative studio that transforms sci-fi expedition ideas into rich in-universe lore dossiers and matching cinematic concept art.

Powered by the **[Pollinations.ai](https://pollinations.ai)** unified multi-modal API.

---

## ✨ Features

- **Multi-Modal Generation**:
  - **Sci-Fi Worldbuilding Lore**: Generates categorized planetary coordinates, tech levels, and expedition logs via Pollinations text completions.
  - **Concept Art Rendering**: Renders photorealistic visuals matching the story using the **FLUX** model on Pollinations.
- **Quick Archetypes**: One-click presets for Ghost Dreadnoughts, Crystal Hive Cities, Solar Dyson Rings, and Cybernetic Archaeology.
- **Art Style Modifier**: Switch between *Cinematic Photoreal*, *Retro 70s Analog Sci-Fi*, *Cyberpunk Noir*, and *Hard Sci-Fi Realism*.
- **Interactive Tools**:
  - 📥 **HD Art Download**: Saves generated artwork directly to your device.
  - 📋 **Copy Dossier**: Formats and copies expedition logs to your clipboard.
  - 🔊 **Voice Narration**: Instant audio dispatch readout of the expedition logs.
- **Zero Install**: Runs entirely client-side in any modern web browser.
